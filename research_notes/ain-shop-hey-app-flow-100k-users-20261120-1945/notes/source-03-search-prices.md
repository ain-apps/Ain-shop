# Search / shopping prices — sources, read 2026-11-20
- Brave Search API: $5/1,000 requests ($0.005), $5 monthly credit (~1,000), 50 req/sec, no free tier since Feb 2026, card required. Terms (Sep 1 2026): no storing/caching beyond transient, no derivative works, no training/benchmarking on results.
  https://www.stork.ai/en/brave-search-api ; https://parallel.ai/compare/brave-vs-parallel ; https://cloro.dev/comparisons/brave-search-api-alternatives/
- Serper: $1.00/1,000 entry ($50/50k), $0.75 at 500k, $0.50 at 2.5M, $0.30 at 12.5M; 2,500 free once, no card; credits expire 6 months; 1 credit up to 10 results, 2 credits for 11-100; rate 50-300 req/sec by pack. Shopping endpoint returns price, merchant, rating, link.
  https://dev.to/serpkite/serp-api-pricing-in-2026-1000-google-searches-on-10-apis-2ml9 ; https://hasdata.com/blog/best-serp-apis ; https://taskfuel.ai/tools/serper-mcp/
- OpenAI built-in web search (for comparison, do NOT use as main): $10/1,000 calls + content tokens.
  https://developers.openai.com/api/docs/pricing?multimodal-image-pricing=batch
- Google Shopping data is a snapshot: price/availability confidence filters exist; no single web-search API guarantees live stock at checkout — re-verify on retailer page/offer before charging.
  https://think.resoneo.com/google-shopping-ai-mode/ ; https://glama.ai/mcp/connectors/com.crawlerdata/google-shopping-serp
